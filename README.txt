ALMOGHANI LIVE — نسخة GitHub Pages التجريبية

الملفات:
index.html : الصفحة الرئيسية التجريبية، تعرض القنوات من بيانات اللوحة.
almoghani-admin.html : لوحة التحكم لإضافة القنوات وترتيبها واستيراد قوائم M3U.

طريقة الرفع:
ارفع الملفين إلى جذر المستودع Aaaa في الفرع main، ثم Settings > Pages > Deploy from a branch > main /root.

مهم:
- لا تتضمن النسخة قنوات عشوائية أو روابط بث غير مؤكدة.
- يجب إضافة روابط بث قانونية ومرخصة من لوحة التحكم، واختبار تشغيلها.
- بيانات هذه النسخة تُحفظ في localStorage بالمتصفح فقط؛ لا تُزامَن بين الأجهزة أو جميع الزوار. ليست لوحة إدارة إنتاجية متعددة المستخدمين.
- تتطلب بعض روابط HLS دعم CORS من مزود البث، وقد تمنع قيود DRM تشغيلها.
- بعض ميزات ZIP/HLS تعتمد على مكتبات CDN واتصال إنترنت.
- لا ترفع بيانات اشتراك أو كلمات مرور خاصة إلى مستودع عام.
